The app can now update itself from GitHub releases.

## What's new
- **Updates window.** A new **Updates** button (top right, beside Log) shows the version you have, the newest release on GitHub and its notes. The app checks once a day and shows a green **NEW** badge when a release is out. You can also press **Check now**.
- **Install with one click.** **Install** downloads the release, gets it ready beside the running app, checks it loads, then restarts into it. Collection pauses for a few seconds. Nothing installs unless you click.
- **Safe if something goes wrong.** If the download or preparation fails, nothing changes. If the new version won't stay running, the app goes back to the old one by itself. After an update you can also choose **Go back** to the version you had.
- **Your data stays put.** Saved switches and their key (`state.enc`, `.state-key`), logs, metric and config history, dashboard layouts, remembered SSH keys and the Windows service files are never moved by an update.

## Behaviour changes to know about
- **A GitHub token is needed** because the repository is private. On GitHub go to Settings → Developer settings → Fine-grained tokens → Generate new token. Set *Repository access* to only `sbs-management-tool` and *Permissions → Contents* to **Read-only**, nothing else. Paste it in the Updates window once. It's stored encrypted with your vault key and only ever sent to GitHub.
- **Dashboard layouts and saved traps/syslog now live in the app folder.** In 1.0.0 and 1.1.0 they were written inside the `routes/` folder by mistake, where an update would have replaced them. They're moved to the right place the first time 1.2.0 starts.
- **`start.bat` now restarts the app after an update.** If you start it with `npm start` instead, start it again after an update.
- The PC running the app needs to reach `api.github.com`, `codeload.github.com` and `registry.npmjs.org` to update.

## Upgrading
This is the last update you install by hand; later ones come through the Updates window.
1. Stop the app (or the service).
2. Get this version: `git pull` on `main`, or download the source zip below and replace the app's files. Keep your existing `state.enc`, `.state-key` and `logs/`.
3. Run `npm ci`. **If you run it as a Windows service**, also run `npm install node-windows` afterwards (the service needs it).
4. Start it again, open http://localhost:3000, click **Updates** and paste your token.
