The Access lists panel (renamed from IP access lists) can now build nearly any rule the switch supports, for IPv4, IPv6 and MAC addresses.

## New: more kinds of IPv4 rules
- **ICMP**, with an optional type and code. For example type 8 is a ping.
- **Any protocol number**, such as 47 for GRE.
- **Ports and port ranges** for TCP and UDP, on the source side, the destination side or both. Leave a port blank for any port.

## New: IPv6 access lists
Choose **IPv6** as the list type when you create a list. IPv6 lists take the same kinds of rules as IPv4 lists, with IPv6 addresses and prefixes.

## New: MAC access lists
Choose **MAC** as the list type. A rule can match a source address, a destination address and a VLAN. The number after the / is how many bits must match: 48 is one device, 24 is every device from one maker.

## Binding lists to ports
A port's **ACL** tab now offers MAC lists alongside IPv4 lists, and has its own place for an IPv6 list. To put a MAC list on a port that already has a list, set the port to (none) first, then choose the MAC list.

## Fixed
- If saving a changed rule fails, the original rule is now put back exactly as it was.

## Not included
A MAC rule can't match an Ethernet type yet.

## Upgrading
Nothing to do. Install the update as usual.
