A fix for the **IP access lists** panel.

## Fixed
- **Access lists on the switch now show in the panel.** The panel read the lists from the switch but lost the part of each answer that says which list and which field it is, so it showed no lists at all. Every list and rule now appears again.
- **Creating a new access list works again.** Because the panel could not see the lists already on the switch, a new list was given a number that was already taken, and the switch refused it with "WrongValue". New lists now get a free number.

The **ACL** tab in a port's or VLAN's details had the same problem and now lists your access lists too.
