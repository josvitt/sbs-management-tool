A shorter, up-to-date README. The app itself has not changed.

## What changed
- **The README is now about 190 lines instead of about 1,600.** It covers what the app does, how to install it, how to run it as a service (the folder must be outside `C:\Users` on Windows), how updates and the GitHub token work, which ports the switches send to, security, settings and where the other documents are.
- **Out-of-date parts were removed.** These included a query bar, presets and a "Compatibility walk" checkbox that are no longer in the app, a builder for SNMP setup commands that was removed, the old performance section (the v1.5.0 speed-up is described in the v1.5.0 release notes and in `docs/SERVER-STANDARD.md`), and wrong defaults (for example the MAC table limit and how many walks run at once).
- **Notes on how the switches behave moved to a new document,** `docs/SWITCH-NOTES.md`. It covers SNMP walks, spanning tree, fetching configs, syslog setup, SNMPv3 ciphers, the console and the MIB database. These are the details a developer needs before changing that code.

## Upgrading
Nothing to do. Install the update as usual.
