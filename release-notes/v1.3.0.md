All IPv4 settings now live in one place: the new **IPv4 Addressing** panel.

## What's new
- **IPv4 Addressing panel.** The "IP routing & DNS" panel is now called **IPv4 Addressing**. It stays where it was on your dashboard. Routing, static routes and DNS work as before.
- **Every interface address in one list.** A new **IPv4 interfaces** section at the top of the panel shows every VLAN and routed port that has an address. It shows the interface, address, prefix, and whether the address is static or from DHCP.
- **Edit from the list.** Click an interface to change its address, or switch it between static and DHCP. **Delete** removes a static address, or turns DHCP off on that interface.
- **Add an address.** **+ Add IPv4 address** asks which VLAN or routed port to use, then shows the usual Static or DHCP form. Only interfaces that don't have an address yet are offered.
- **The management address stays locked.** The address this app uses to reach the switch shows a lock. It can't be changed or deleted from here, just as before.

## Behaviour changes to know about
- **The VLAN window no longer has an IPv4 tab.** Set a VLAN's address in IPv4 Addressing. The VLAN table still shows each VLAN's address, but you can't edit it there.
- **The port window no longer has an IPv4 tab.** After you make a port routed on its **Switchport** tab, set its address in IPv4 Addressing. The Interfaces table still shows a routed port's address, but you can't edit it there.
