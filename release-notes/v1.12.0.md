A new Spanning tree settings panel and a Spanning tree tab on every port let you change how the switch runs spanning tree.

## New: Spanning tree settings panel
- **Turn spanning tree on or off** for the whole switch. Turning it off asks you to confirm first.
- **Change the mode** between STP, RSTP, MSTP, PVST+ and Rapid PVST+. The app asks you to confirm, because every switch on the network rebuilds its tree and traffic stops for a few seconds.
- **Set the bridge priority** in steps of 4096. The lowest priority becomes the root bridge.
- **A row for every port** showing its priority, cost, PortFast and BPDU guard, with a button to change them.

## New: Spanning tree tab on each port
Open a port and choose **Spanning tree**.
- Turn spanning tree on or off for the port.
- Set the port priority and cost. A cost of 0 lets the switch choose it from the link speed.
- Set PortFast to on, off or automatic, for ports with a computer, phone or printer.
- Turn on BPDU guard, which shuts the port down if someone plugs a switch into it.

## Not included
Catalyst 1200 and 1300 switches don't accept a bridge priority or port cost for a single VLAN over SNMP. The panel tells you to set those on the switch's own web page. The Spanning tree panel still shows what each VLAN is running with.

## Upgrading
Nothing to do. Install the update as usual.
