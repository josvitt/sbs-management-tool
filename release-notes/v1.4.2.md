Every panel now follows the same standard. Forms open in the same window across the app, buttons ask for a second tap only when a change is hard to undo, and **Spanning tree**, **Flash files** and **Packet capture** now update in place like the other panels.

## What's new
- **The SNMP community this app connects with can't be deleted.** Its row in **SNMP configuration** shows a lock with "in use" instead of a Delete button. The switch refused that delete anyway. The same applies to the SNMPv3 user when you connect with SNMPv3.

## Forms open in the standard window
- **Switch identity.** The pen next to the system name opens the name, location and contact in the standard window. **Save** acts on one tap, **Esc** closes it, and an error shows as a red line under the button.
- **RADIUS and TACACS+ servers.** Each list is a table with **+ Add RADIUS server** or **+ Add TACACS+ server** above it. Tapping a server's address opens it in the standard window, with a **Counters** tab for RADIUS servers. Adding and saving take one tap. If you type a shared key while connected without SNMPv3 privacy, the button asks for a second tap, because the key is sent in cleartext.
- **The tables update in place.** After a change, only the rows that changed move, as in the other panels.
- **Port channel membership.** Editing a channel's members opens in the standard window, with no Cancel button. **Save** still asks for a second tap, because the channel is rebuilt. **Clear** appears only when the channel has members, and asks for a second tap.

## Which buttons ask twice
- **One tap now:** Save VLAN name, Create VLAN, Add IPv4 address, Add static MAC, Voice VLAN Apply.
- **Still two taps:** every delete, changing an existing IPv4 address, port speed and duplex, switchport mode, 802.1X port settings, and turning 802.1X on or off for the switch.
- **No more Yes/Cancel rows.** **Save running to startup** and **Configure this switch** (on the Events panel) now ask for a second tap on the same button, like every other confirm.

## Under the hood
- Unused styles and an old inline editor were removed.

## Spanning tree
- **Updates in place.** When the switch is re-read, only the values that changed move, such as BPDU counts and topology changes. Before, the whole panel was cleared and rebuilt.
- **Refreshes when per-VLAN or MST data changes.** Before, a refresh of only the per-VLAN or per-instance tables did not repaint the panel.

## Flash files
- **"Waiting for data…"** shows while the list loads for the first time, as in the other panels.
- **Updates in place.** Deleting a file removes its row without rebuilding the list.
- **Refresh re-reads the list.** Before, it rebuilt the panel.
- **A file you just exported is highlighted** when it appears in the list. This highlight was missing before.

## Packet capture
- **The settings open in the standard window.** Use **+ New capture** to create one, or tap a capture's name to change it. **Create capture** and **Save** act on one tap, **Esc** closes the window, and an error shows as a red line under the button. The form no longer sits permanently under the list, and the separate Edit button is gone.
- **Updates in place.** Start, Stop, Clear and Delete change only their row. While a capture is running, its packet counts still update every 15 seconds.
- **"No captures on the switch"** shows when there are none, under **+ New capture**.
