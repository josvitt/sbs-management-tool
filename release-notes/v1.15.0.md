A new **IPv6 addressing** panel sets up IPv6 on the switch: which interfaces use it, their addresses, static routes and DNS servers.

## New: IPv6 on each interface
- See every interface with IPv6, its link-local address, the global addresses it has, and whether it takes an address by autoconfig or DHCPv6.
- Turn IPv6 on or off for a VLAN interface or routed port, and turn autoconfig on or off. Autoconfig keeps IPv6 on, so turning IPv6 off turns autoconfig off too.
- Add a global address to an interface, or remove one you added. The switch takes one address per network (/64) on an interface.

## New: IPv6 static routes and DNS servers
- Add a static route, or a default route (::/0), through a next hop, and remove it. The panel shows whether each route is in use.
- Add or remove the IPv6 DNS servers the switch uses to look up names.

## Safer
If the app reaches the switch over IPv6, it will not let you remove that address or the default route, so you cannot cut off your own connection.

## Also fixed
Test recordings of a switch no longer keep the switch's own hardware address.

## Upgrading
Nothing to do. Install the update as usual.
