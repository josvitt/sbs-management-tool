A new **QoS** panel sets how the switch sorts traffic into its queues, and how fast each port may send and receive.

## New: QoS mode and trust
- See and change the QoS mode (off, basic or advanced) and what the switch trusts to sort traffic: the 802.1p priority (CoS), DSCP, or both.
- Turn trust on or off for each port.

## New: rate limits and shapers per port
- Set a rate limit on what comes into a port, and a shaper on what goes out of it, in kb/s. Set 0 to turn either off.
- Shape a single egress queue on a port, for example to hold one class of traffic to a set rate.

## New: queue maps
- See which of the 8 queues each CoS value goes to, and which DSCP values go to a queue other than the default.
- Send a CoS or DSCP value to another queue, or put either map back to the switch's defaults.

## Not included
Policy maps and class maps are not changed by the app. Advanced mode keeps the ones the switch already has.

## Upgrading
Nothing to do. Install the update as usual.
