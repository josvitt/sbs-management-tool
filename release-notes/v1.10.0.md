The new System panel shows a switch's clock, time servers, local users and management services, and lets you change the ones the switch accepts over SNMP.

## New: System panel
- **Clock and time zone.** See the switch's time, where it gets it from, and when it last synchronized. Set the time zone, or set the clock from your computer's time.
- **SNTP.** Turn time synchronization on or off, and see each time server with its status.
- **Local users.** See every user with their privilege, failed sign-ins and whether they are locked out. Change a user's privilege or delete a user. The app never removes or demotes the last admin.
- **Management services.** Turn SSH, Telnet, HTTPS and HTTP on or off. Telnet and HTTP show in yellow when on, because they send passwords unencrypted. The app won't turn off the last way to sign in.

## Not in this release
- **Adding time servers, adding users and setting passwords.** The C1300 refused every SNMP form of these we tried. The panel lists them and tells you where to change them on the switch's own web page.
- **Summer time and the management access list** are shown but can't be changed yet.

## Upgrading
Nothing to do. Install the update as usual.
