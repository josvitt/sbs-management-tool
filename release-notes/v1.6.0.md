Every panel now opens straight away with the switch's latest data, and updates no longer need a GitHub token.

## Every panel works the same way
- **SNMP configuration, Flash files, Packet capture, ACL, the IPv4 route table and the MAC table open instantly.** Before, these panels showed "Waiting for data…" and read the switch each time you opened them. Now the server reads them in the background like every other panel, so they open from the last poll.
- **How often each one is read:**
  - **Every 5 minutes, with the rest:** ACL, the route table, the capture list and the MAC table.
  - **Only when something may have changed:** SNMP configuration and Flash files. They're read again after a change made from this app, a config change, a reboot, a manual **Refresh**, or once an hour.
- **Changes still show at once.** After you add, edit or delete something, the panel re-reads just what changed, as before. While a capture is running and its panel is open, packet counts still update every 15 seconds.
- **Still gentle on the switch.** SNMP configuration now reads each of its tables once instead of up to four times (about 20 requests instead of 35). Flash files reads only the columns it shows (about 5 requests instead of 20). Everything stays under the 100 requests-per-second limit added in v1.5.0.

## Updates without a GitHub token
- **Updates work with no GitHub token.** The app checks for and downloads new versions from the public repository without signing in to GitHub. You no longer need to make a token or paste one into the Updates window.
- **A token is now optional.** GitHub allows about 60 update checks an hour from one internet address without a token. That's plenty for one PC. If many PCs share one address and the Updates window says the hourly limit is used up, you can still add a token. The Updates window now calls this section "GitHub access (optional)".
- **An old or expired token no longer blocks updates.** If GitHub refuses the token you saved earlier, the app checks again without it, and the Updates window says the token was refused so you can remove it.
- **The README and the server document** now describe updates without a token, and the README says where to download the app.

## Upgrading
Nothing to do. Install the update as usual. If you saved a token earlier, you can keep it or remove it in the Updates window.
