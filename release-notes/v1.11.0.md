The new Port features panel and a Features tab on every port let you change PoE, port security, storm control, discovery and mirroring, and run a cable test.

## New: Features tab on each port
Open a port and choose **Features**.
- **Power over Ethernet.** Turn power on or off, set the priority (critical, high or low) and a power limit in watts. See how much the device draws and its class.
- **Port security.** Lock the port and choose how it learns devices, up to an address limit. The app warns you not to lock the port your computer uses to reach the switch.
- **Storm control.** Set limits for broadcast, multicast and unknown unicast traffic in kb/s. 0 turns a limit off.
- **LLDP, CDP and Energy Efficient Ethernet** for the port.
- **Cable test.** Measure the cable length on a working gigabit link, or run a full test that checks each pair. The full test takes the link down for a few seconds, so the app asks you to confirm first.

## New: Port features panel
- **Switch-wide settings.** Turn LLDP, CDP and Energy Efficient Ethernet on or off for the whole switch.
- **Shut-down ports.** See which ports the switch has shut down (errdisable) and why, choose which causes it recovers from by itself, and set how long it waits before recovering.
- **Port mirroring.** See each mirroring session. Start one by copying one or more ports to another port, add ports to a session that already exists, or remove a session.
- **A row for every port** showing its PoE, port security, storm control, LLDP and EEE, with a button to change them.

## Faster reads
The app reads these settings only for the ports your switch has, not every possible port number. On a 24-port switch that's about 130 requests instead of over 600.

## Upgrading
Nothing to do. Install the update as usual.
