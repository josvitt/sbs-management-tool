The new Reboot and firmware panel lets you restart a switch, schedule a restart, choose which firmware it starts next and install new firmware, all from the app.

## New: Reboot and firmware
- **Reboot now or later.** Restart the switch right away, or pick a time from 5 minutes to 8 hours out. A scheduled restart can be cancelled. The panel warns you if the switch has unsaved changes, because a restart loses them.
- **See both firmware images.** The panel lists the two images the switch keeps, with their versions and build dates, and shows which one is running and which one starts next.
- **Choose the image to start next.** "Boot this next" sets which image the switch starts after its next restart.
- **Install firmware.** Choose a firmware file on your computer and the switch copies it from the app into the image it is not running. The running image stays as a fallback. The switch then starts the new image after its next restart. A 65 MB image takes about two minutes.

## Not in this release
- **Restoring a saved configuration is held back.** On firmware 4.1.9.92 the switch quietly drops some lines from a configuration copied into it this way, so a restore could lose settings. Config history still lets you view and compare saved versions.

## Upgrading
The firmware install uses the app's built-in TFTP server, so the switch must be able to reach this computer on UDP port 69 (or the port set in TFTP_PORT). Nothing else to do.
