The **IP access lists** panel now looks and works like VLANs and IPv4 Addressing, and can delete a whole list.

## What's new
- **Delete a whole access list.** Each list has a **Delete ACL** button next to **+ Add rule**. It removes the list and all of its rules. Tap it twice to confirm.
- **Lists in use are protected.** A list that is bound to a port or VLAN shows a lock instead of Delete, and its heading says "bound to an interface". Unbind it on that port's or VLAN's **ACL** tab first. Lists the switch created itself are locked too.
- **Editing a rule keeps its place.** A rule you edit stays at the same position in the list. Before, it moved to the end, which could change what the list lets through.
- **A failed edit no longer loses the rule.** If the switch refuses the new version of a rule, the original rule is put back and the message says so.
- **Rules this editor can't show in full open read-only.** A rule that matches something the form doesn't offer, such as a port number or ICMP, opens with an explanation instead of a form, so saving it can't drop part of the match.

## Behaviour changes to know about
- **Looks like the other panels.** Each list has an amber heading with its rule count. **+ New ACL** and **+ Add rule** sit under their headings, above the table.
- **Refresh does what it says.** The panel's Refresh button re-reads the access lists. Before, it re-read the rest of the switch and not the lists.
- **No more "No access lists found" flash.** While the lists load, the panel says "Waiting for data…".
- **Delete shows its progress.** Deleting a rule spins until the row is gone. If the switch refuses, the button says so.
- **Adding is one tap.** **Add rule** and **Create ACL** act on the first tap. Saving an edit and every delete still ask for a second tap.
- **Esc closes the rule window**, as it does everywhere else.
- **Tidier switch.** Deleting or editing a rule also removes the match entries it no longer needs. Before, they were left behind on the switch. A failed add leaves nothing behind either.
- **Port and VLAN ACL tab.** The list offers only IPv4 access lists, and **Apply binding** waits until the switch confirms the change.
